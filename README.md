## Overall structure
 MFDFNet is a steel surface defect detection network that centers on multi-scale feature extraction and employs a dual branch fusion strategy.Its architecture is depicted in the figure below.The feature extraction module forms the core of MFDFNet and contains three submodules, designated LGF, UID, and LCN.
